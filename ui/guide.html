Welcome to MailForge

MailForge lets the outreach team write one email, fill it automatically for every company on the sheet, and then either save everything as Gmail drafts or schedule it to go out at an exact time. Nothing is ever sent without you pressing a confirm button.

Start a mail merge → Jump to step 1

1

Sign in with your Google account

Open the platform, click Sign in with Google, and choose your institutional account. If you are part of the team you land straight in; otherwise a request is sent to the admins automatically.

New person on the team? The admin can either invite your email (Team admin page) or approve your request. Once approved you can sign in any time - your login is remembered on this computer.

2

One-time setup: connect team sign-in (admin only, ~10 minutes)

The very first person to set up the platform does this once in Google Cloud. You paste the results into Settings - nothing is installed.

  1. Go to console.cloud.google.com and sign in. Create a project (any name, e.g. "mailforge").
  2. Open APIs and Services → OAuth consent screen. Choose External, fill in app name + your email. Under Scopes add openid, email, profile. Under Test users add every team member's email (skip this if the consent screen offers Internal and your domain is verified - then nobody needs to be a test user).
  3. Open APIs and Services → Credentials → Create credentials → OAuth client ID. Type: Web application. Under Authorized redirect URIs add exactly:
    http://localhost:5001/api/google/callback
    Create, then copy the Client ID and Client secret.
  4. Paste both into Settings → Google sign-in (admin section) and save.
3

One-time setup: the Gmail sending client (admin only, ~10 minutes)

This lets the platform create drafts and send emails from the team's Gmail account. Same Google Cloud project as before.

  1. In the project, open APIs and Services → Library, search Gmail API and press Enable.
  2. Go to Credentials → Create credentials → OAuth client ID. Type: Desktop app. Create.
  3. Press Download JSON on the new client. Open the file, select all, copy.
  4. In MailForge: Settings → Gmail API client → paste the whole JSON → Save.
  5. Then in Settings → Gmail send-accounts click Connect a Gmail account, sign in with the team's Gmail (e.g. the team account). It now shows in the list for the whole team.

The account is saved on the platform for everybody on the team. You can connect more accounts (e.g. a second team mailbox) - each stays available in the dropdown wherever you choose "send from".

4

Load the company list (Contacts)

Go to Contacts and click Import sheet. Upload your CSV or Excel file with columns like Serial No., Company, HR Name, HR Email (other names work too - the platform guesses). Importing the same sheet again updates rows instead of duplicating them.

5

Add your email template

Go to Templates and click Upload template. A Word (.docx) file works - put replaceable words in curly braces, square brackets or guillemets, e.g. {recruiter_name}, [Company]. Images in the Word file come along automatically. You can also let ✦ AI create a template from a short brief.

6

Run the mail merge

Mail Merge page, three steps: pick the template → say which sheet column replaces each field (suggestions are pre-filled, AI can double-check) → preview real rendered emails → Generate queue. Choose which Gmail account the batch uses.

7

Draft, schedule or send

On the Queue and Schedule page, select rows (or leave it on "pending") and pick one action:

  • Create drafts - lands in the account's Gmail Drafts folder. Nothing sends.
  • Schedule send - pick date and time (e.g. 2026-11-12 10:30) and an optional stagger. The platform's built-in worker sends them itself at the exact time, and they appear in the account's Sent folder at that moment. You can also tick automatic follow-up reminders in the merge wizard so unanswered recruiters get a polite reminder after a set number of days.
  • Send now - only possible when Safe mode is off, and it always asks you to type SEND.

The platform must be running on a powered-on computer at the send time. If it was off, the next run either sends the due emails (default) or marks them missed - your choice in Settings.

8

Watch and adjust

Dashboard shows the pipeline at a glance; Activity records every action with the person who did it; Contacts shows each company's status (new → drafted → scheduled → sent). Admins manage people under Team admin.

9

Track replies, follow-ups and reports

Outreach Reports shows everything bucketised: how many went out each day, the pipeline (pending / drafted / scheduled / sent / replied / error), which companies you have reached out to the most, and a table of every single email. Replies are detected automatically (the platform checks the sender's inbox for replies to each sent mail) - you can also mark one manually from the Queue's email preview. Sent emails keep tracking their reminder count.

Other useful places: Settings → Email signature (saved once, auto-appended to text and AI templates), Mail Merge step 3 (attachments + follow-up reminders), Templates (AI can polish a template or write a reminder for you).
